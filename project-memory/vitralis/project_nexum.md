Nexum is a blockchain username registry positioned as pure identity (not DNS/URLs like ENS). Usernames like `ran#` are owned as soulbound NFTs, usable as login across any app. Planned cross-chain with Polygon as canonical chain.

**Why:** User wants usernames to be truly ownable, with no suffix (.eth etc), special character support, and cross-chain identity from day one.

**How to apply:** When user mentions Nexum, refer to concept.md for full spec. Key open question is what app to build on top of it — identity layer needs an app to have value.
