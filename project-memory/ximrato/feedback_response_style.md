name: Response style — speed
description: User wants fast, direct answers with minimal analysis overhead
type: feedback
---

Give results fast. Skip lengthy reasoning chains, hypotheses, and "I'm going in circles" loops.
Lead with the answer or the fix, not the investigation narrative.

**Why:** User explicitly asked for faster results after a long diagnostic response.

**How to apply:** When diagnosing bugs — state the most likely cause first, show the relevant code, done. Don't enumerate every possible hypothesis. If unsure, pick the best guess and say so in one sentence.
