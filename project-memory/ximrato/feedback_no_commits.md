Do not commit to the `ximrato` repo. Commits are fine in `ximrato-app` and `ximrato-server`.

**Why:** User preference — they manage commits in `ximrato` themselves.

**How to apply:** Never run `git commit` in `d:/Users/{USER}/sw/ximrato`. Committing in `d:/Users/{USER}/sw/ximrato-app` and `d:/Users/{USER}/sw/ximrato-server` is allowed.
