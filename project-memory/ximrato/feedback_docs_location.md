---
name: docs location
description: where to put project documentation and specs
type: feedback
---

Do not create standalone spec or documentation files at the repo root. Use the README and a `docs/` folder within each repo. For multi-repo projects, split the relevant specs between the repos where they belong.

**Why:** user corrected ad-hoc SPEC.md creation — docs belong in README/docs/, not as one-off root files.

**How to apply:** when writing specs or documentation during planning, wait until the repo is set up and write directly into its README or docs/ folder.
