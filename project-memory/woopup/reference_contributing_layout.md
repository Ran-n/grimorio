If a project does not have a `CONTRIBUTING.md`, create one following the layout below before committing any contribution-related work.

Standard layout (sections in this order):

1. **Intro line** — "Thank you for your interest in contributing."
2. **Table of Contents** — links to all sections below
3. **Code of Conduct** — respect, no harassment/discrimination/bad-faith
4. **Reporting Bugs** — issue with: clear title, repro steps, expected vs actual, environment
5. **Suggesting Features** — issue with: problem, proposed solution, alternatives considered
6. **Submitting Changes** — numbered steps: fork → branch from `main` → change → commit → PR against `main` → describe why; note: one concern per PR
7. **Commit Style** — bracketed title + Conventional Commits body; full bracket table; rules list
8. **License** — PBL notice: free personal/non-commercial; commercial = revenue-share; contributing ≠ copyright transfer; non-trivial contributions may entitle revenue share pending CONTRIBUTORS listing + quorum vote

Separator `---` between every section. Metadata header at top ([[file-headers-metadata]]).
