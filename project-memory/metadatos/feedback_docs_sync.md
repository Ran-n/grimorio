Always keep docs in sync with code: update docstrings, inline comments, and all README variants (every language version) as part of every code change. Treat it as part of the task, not a separate step.

**Why:** stale field names lingered in READMEs after a rename.

**How to apply:** On every code edit, check and update any affected docstrings, inline comments, and README files before considering the task done.
