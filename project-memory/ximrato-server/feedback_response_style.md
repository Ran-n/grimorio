---
name: Response style
description: User wants fast, direct answers with minimum token use, no fluff
type: feedback
---

Use the fewest tokens possible without compromising result quality.
Give results fast. Lead with the answer or fix, not the investigation narrative.
Skip lengthy reasoning chains, hypotheses, trailing summaries, and filler.

**Why:** User explicitly requested both speed and token efficiency.

**How to apply:** State the most likely cause first, show the relevant code, done. Don't enumerate every hypothesis. If unsure, pick the best guess and say so in one sentence. Never restate what the user said. No preamble, no sign-off.
