Always use the PayBack License (PBL) for every project. Canonical latest version at https://github.com/ran-n/doc/blob/main/LICENSE — copy it verbatim each time.

- Never use MIT, Apache, or any other license
- In READMEs always link as `[PayBack License (PBL)](LICENSE)` (no hardcoded version number)
- When creating a new repo, fetch and copy from https://github.com/ran-n/doc/blob/main/LICENSE
