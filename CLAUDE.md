# Global triggers

These plain-text messages are explicit requests, in every project, same as their slash commands:

- **"todo: …"**, **"todo …"**, **"add to the todo/backlog …"** → run `/todo` (`~/.claude/commands/todo.md`) with the text: add a self-contained item to the project's `TODO.md`.
- **"do todo N"**, **"do the next todo"**, **"show the todo"**, **"refine todo N: …"**, **"move todo N to the top"**, **"drop todo N"** → the matching `/todo` action from the same file.
